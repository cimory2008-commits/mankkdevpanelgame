Alur kerja

Tiga langkah, tanpa ribet

Reseller hanya perlu login dan mengontrol; semua urusan koneksi diatur Admin.

1

Admin buat akun reseller

Tentukan username, password, dan masa sewa aktif untuk tiap client.

2

Admin setel game

Hubungkan Universe ID dan API Key Roblox ke akun reseller yang bersangkutan.

3

Reseller kontrol game

Reseller login dan langsung bisa restart server, ubah metadata, dan atur visibilitas.
